## the why

Why begets knowledge. Here's the why.

**debian, because it works.**
Simple and dumbproof - when you treat it for what it is. Debian is a dumbass
cobble of stuff gaggled together to do stuff and offer function - and it never
gets up in your face. It just works. That's the whole pitch. We don't marry an
OS - we marry a methodology, a function. We adapt when we gotta, or we run
that same function for twenty years. Debian ticks the boxes; that's the OS.

**openbox, because light.**
The window manager is light and it gives us everything we need - and DORiS is
built around it, so why install anything else that adds bloat and overhead?
That's the case for it; nothing against anyone else's pick. We just don't
install what we don't use. I mean, sometimes.

**the terminal, because control.**
We like fast, succinct commands we can control, with a readout we can see.
That's all - not because we're l33t. (l33t? wtf issat.) Commands are purposeful,
same as apps in linux: one thing, done well. We make scripts out of commands
we run more than twice. We use aliases because we already ran that longass
command - and we're in the terminal anyway. We tinker. Type, see, adjust.
That's the culture. We also doom-scroll and stream mindless 'content', or, whatever.

**passwords, because respect.**
keepassxc ships installed because that's how smart people take care of
passwords - respect the whole thing. It even has a browser extension, so the
function stays a wrist-flick. Password managers inside the browser are the
suck - we don't use them, and we move past that.

**mail, because it keeps working.**
claws-mail is fast, reliable, handles anything - and old filters
and actions still work in it. Filtering and whatnot you never have to mess
with, because they work. That's the kind of tool you keep.

**right-click, because you're already there.**
Encrypt, zip, extract - right there in the file manager, because you're
looking at the file in a file manager anyway. Do it on the spot. Wrist-flick
or why bother. There's so much right-click action in Thunar because they make
it easy to do, just like Openbox does. Even added Nautilus Scripts in there for more.
Now, you can edit those fancy right-click actions in thunar's own dialog: 
edit --> configure custom actions, or, and of course, you could just edit
the config file: ~/.config/Thunar/uca.xml. Syntax is easy, have a look. Now you're cookin'.

**and the people:**
Most folks run Windows because machines come with Windows on them - and they
never learn what the box does, or what it can do. Cool. I guess. We don't throw money at
problems or leave them be, either; we solve them with what's in front of us. Any of us was born only
knowing how to suck - nobody starts knowing. The n00b isn't lesser, just new.
We love our users, readers, community - we don't pander. We don't say
"concurrently" - we don't pontificate, and we just want to be left alone, lol.
So - debian. I mean, d'uh.


**and DORiS itself:**
A great OS with a reliable, functional, customized Debian setup with Openbox - about the
same and evolved little for maybe twenty years, easily seventeen. DORiS restores
a setup; it doesn't try to be a distro. What beats Debian?
